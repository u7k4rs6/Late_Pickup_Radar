# data/sample: the committed sample

Generated by `make sample` (`pipeline/sample.py`); do not edit by hand. Used by `make demo`, the
test suite and CI, which never touch the network (`--offline` / `--sample-file`).

## How it was made

- Source: `data/raw/2026-07/fhvhv_tripdata_2026-07.parquet`, sha256 `8da280d9d23813aae02a6e1d1d1caa8b96eb5e8d38efcbc9a570faf1e418f5a8`, 20,921,249 rows.
- Deterministic hash sample: `md5(concat_ws('|', hvfhs_license_num, dispatching_base_num, pickup_datetime, dropoff_datetime, PULocationID, DOLocationID, trip_miles)) % 400 = 0` gives 52,393 rows (the same
  hash as `--sample`, so business-key groups such as pooled riders stay together).
- Rules with real examples in the month but none in the hash sample got up to 5 of their real
  rows appended (lowest `file_row_number` first): R01 (5), R03 (5), R06 (5), R02 (2).
- **No rows are fabricated.** Rules with no real example this month are covered only by the
  per-rule synthetic tests in `tests/test_validate.py`.
- Total: **52,410 rows**, same 25-column schema, rows in original file order.
